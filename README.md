# 🥬 EcoFridge AI

**Zero-waste умный холодильник для семей Астаны.** Проект для эко-хакатона **AuaHack** (г. Астана).

## Проблема

Казахстанские семьи ежегодно выбрасывают тонны продуктов, которые просто забыли съесть вовремя. Это:
- прямые финансовые потери для семейного бюджета;
- лишняя нагрузка на полигоны Астаны — пищевые отходы на свалке выделяют метан (в ~2.5 раза сильнее CO₂ по эффекту), усиливая парниковый эффект.

## Решение

EcoFridge AI — веб-приложение, которое ведёт учёт продуктов в холодильнике, предупреждает о скором истечении срока годности и подсказывает, что приготовить из того, что нужно съесть прямо сейчас.

Ключевые функции:
- 📋 **Умный список холодильника** — продукты со статусами `urgent` / `warning` / `fresh` по сроку годности.
- 🧾 **Сканирование чека** — фото чека или холодильника распознаётся через AI (Gemini / OpenAI при наличии ключа) или демо-режим с реалистичным fallback без ключей и интернета.
- ➕ **Ручное добавление продукта** в холодильник.
- ✅ **«Съели»** — отмечаем продукт съеденным, деньги и CO₂ уходят в копилку семьи.
- 🍳 **Генератор Zero-Waste рецепта** из продуктов, которые скоро испортятся (AI + умный fallback-генератор).
- 💰 Эко-метрики семьи: сколько тенге сэкономлено, сколько «под угрозой», сколько кг CO₂-эквивалента метана предотвращено.

## Стек

- **Backend:** Python, FastAPI, Uvicorn, httpx
- **Frontend:** статический HTML/CSS/JS (раздаётся самим backend'ом)
- **AI (опционально):** Gemini / OpenAI для распознавания чеков и генерации рецептов, с надёжным локальным fallback-режимом

## Структура проекта

## API эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/state` | текущее состояние холодильника и эко-метрики семьи |
| `POST` | `/api/items` | добавить продукт вручную |
| `POST` | `/api/scan-receipt` | распознать чек/фото (файл или `{"demo": true}`) |
| `POST` | `/api/consume/{item_id}` | отметить продукт съеденным, обновить метрики |
| `POST` | `/api/generate-recipe` | сгенерировать Zero-Waste рецепт из продуктов под угрозой |

Полная интерактивная документация доступна на `/docs` (Swagger UI).

## Запуск локально

```bash
pip install -r requirements.txt
uvicorn backend.main:app --reload
```

Приложение откроется на `http://127.0.0.1:8000` — там же раздаётся фронтенд.

### Переменные окружения (опционально)

Без них всё работает в полнофункциональном демо-режиме с реалистичным fallback.

```bash
GEMINI_API_KEY=...   # для распознавания чеков/рецептов через Gemini
OPENAI_API_KEY=...   # или через OpenAI
```

## Деплой на Render

Репозиторий содержит `render.yaml` — достаточно подключить GitHub-репозиторий в [Render](https://render.com) как Blueprint, и сервис соберётся и запустится автоматически (`pip install -r requirements.txt` → `uvicorn backend.main:app`).

Проект создан в рамках эко-хакатона **AuaHack** (г. Астана) — цель: сократить пищевые отходы и их углеродный след на уровне отдельной семьи с помощью доступных и понятных digital-инструментов.
